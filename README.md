\# ChemVenture / Green Paints Website



Official website redevelopment project for ChemVenture India Private Limited and the Green Paints powder coating brand.



\## Development Approach



The project is being executed in six stages:



1\. CV-01 - Responsive Design Master

2\. CV-02 - WordPress + Git Foundation

3\. CV-03 - Complete Homepage Build

4\. CV-04 - Lead Generation + Tracking

5\. CV-05 - Polish, Mobile, SEO + Hardening

6\. CV-06 - Production Deployment + Verification



\## Current Status



CV-01 - In Progress



The HTML design master will act as the visual source of truth before WordPress development begins.



\## Planned Stack



\- HTML / CSS / JavaScript design master

\- Git + GitHub
