# Green Paints Website - Cookie Policy

**Last updated: September 2026**

This Cookie Policy explains how the Green Paints website operated by ChemVenture India Private Limited uses cookies, local storage, session storage and similar browser technologies.

## Necessary storage

Necessary browser storage can be used to remember privacy choices and support core website and security functions. The consent preference is stored under `chemventure_cookie_consent`.

## Enquiry attribution

During a browsing session, the website can temporarily store campaign context under `chemventure_campaign_attribution`, including UTM values, landing URL, referrer and advertising click identifiers when present. This allows a submitted enquiry to be associated with the campaign or page that generated it.

## Optional analytics and campaign measurement

When configured for production, Google Tag Manager can load optional measurement services such as Google Analytics 4 or Meta Pixel. These services remain blocked until the visitor chooses **Accept optional**. Rejecting optional measurement does not prevent the website or enquiry form from working.

## Changing a choice

Visitors can reopen the consent panel using **Cookie settings** in the footer. Clearing browser website data also removes stored consent and session attribution.

## Retention

The consent choice remains in browser local storage until it is replaced, cleared or the consent version changes. Session attribution normally ends with the browsing session. Third-party analytics or advertising cookies, when accepted and configured, follow the retention settings of those services and the browser.

## Contact

Questions about cookies or personal data can be sent using the privacy contact details published in the website Privacy Policy.
